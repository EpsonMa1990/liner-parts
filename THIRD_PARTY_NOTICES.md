# Third-party components

Agamaship parts workbench (formerly Liner Parts) source is MIT licensed. Dependencies and their bundled components retain their own licenses.

The Windows build script includes dependency license texts in `licenses/`, including PDFium's build notices, the Python runtime notice, pywebview and its bundled component notices, and Vue / Lucide frontend notices. `licenses/DEPENDENCIES.json` records the installed versions used during packaging, including development tools where applicable.

Core components: Python, Flask, Werkzeug, Waitress, HTTPX, PDFium / pypdfium2, Pillow, openpyxl, platformdirs, keyring, pywebview, pythonnet, Vue, and Lucide. Consult the bundled source notices for the full terms and attribution, rather than treating the application's MIT license as applying to all dependencies.

Microsoft Edge WebView2 Runtime is a separately installed system component; this distribution does not bundle its installer. The original practice manual is generated by this application and does not contain a commercial model manufacturer's instruction book.

The optional Windows installer is built with Inno Setup (Jordan Russell and Martijn Laan). Inno Setup retains its own license; see https://jrsoftware.org/files/is/license.txt. The application's MIT license does not replace the terms of the installation builder.
